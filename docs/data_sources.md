# Data sources and release decision

This local release candidate contains **only selected aggregate result/figure-source tables and city-level map metadata**. No sampled coordinates, class-labeled point rows, annual embedding vectors, raster tiles or frozen external prediction rows are present. The repository's MIT License covers project research code only; it does not license these CSV tables or third-party data. The Earth Engine extraction scripts and private asset identifiers are not included.

## Recorded product and asset identifiers

The historical workflow used these public Earth Engine collection/image identifiers: annual AEF `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`, Dynamic World `GOOGLE/DYNAMICWORLD/V1`, ESRI/Impact Observatory land-cover time series `projects/sat-io/open-datasets/landcover/ESRI_Global-LULC_10m_TS`, and GHSL 2020 built-up surface `JRC/GHSL/P2023A/GHS_BUILT_S/2020`. The exact accessibility and provider terms must be checked in the user's own Earth Engine account. City-boundary assets, sampled-point assets and project IDs were user-specific inputs; none is distributed or specified as a public asset path.

Point sampling used authorized city boundaries, 10 m land-cover consensus information for 2020/2022/2024, and 2020 GHSL urban context; the annual 64-band AEF features were sampled at the same 18,000 points per city (6,000 per class), then exported as three annual CSVs. The two-city historical sample selection also depended on a private precomputed Dynamic World consensus asset. Consequently, a new export following the documented protocol is a reconstruction, not guaranteed to reproduce the original point identities or byte-identical frozen external intermediates. The required CSV schema, filenames and processing destinations are in [`data/README.md`](../data/README.md).
