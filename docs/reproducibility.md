# Reproducibility boundaries

The frozen experiments use seeds `20261008`–`20261012`, 2 km group-aware spatial blocks and AEF-192 (annual 64-dimensional 2020/2022/2024 embeddings). The 2020/2022/2024 stack, not latitude, longitude, city or class metadata, is the model feature set. The checked-in `config.json` carries the full original model settings. Standardization is fitted to source/training data only where applicable. Same-city references and source-trained cross-city models are evaluated on **identical target held-out test blocks**; target labels are never used to fit zero-shot source models.

The 20 directed development pairs are the units of transfer-risk inference; QAP permutes city-node labels over all 120 relabelings, not 20 independent pair observations. R1 was predefined. Predictive-entropy R4 was selected post hoc during development. The risk specification and predictions were frozen before external outcomes were revealed. The external prediction script intentionally checks byte-level hashes of processed Parquets and creates a manifest. Rebuilding semantically equivalent Parquets without identical bytes will not pass that exact historical gate; do not bypass it silently.

## Reproduction tiers

1. **Packaged integrity:** `python -m unittest discover -s tests -v` verifies the reported canonical values and static file/path constraints without retraining.
2. **Aggregate-figure rendering:** main Figures 1, 3–6 and supplementary S16–S20 can be rendered from bundled code and aggregate tables. S16/S17 use `scripts/paper_figures/make_external_comparison_s16_s17.py`; their values and same-city reference lines are checked against the submitted scientific content, while pixel identity is not claimed. Figure 2 additionally requires seven processed city Parquets and the separately obtained Natural Earth archive at the path and hash specified in its script. The selected 6 × 6 km window bounds are bundled only as an aggregate summary. See `expected_outputs.md` for all 26 figure tiers.
3. **Model rerun:** obtain the public source products and independently prepare the documented Earth Engine point/annual exports; no GEE JavaScript or private assets are bundled. Then regenerate processed Parquets, split tables and frozen artifacts using the retained Python scripts. Read `PAPER_TO_CODE_MAP.md`, `data/README.md` and `data_sources.md` before execution. No raw feature vectors are bundled. New point samples need not have the original historical identities.
4. **Exact external historical replay:** additionally requires the original byte-identical processed Parquets and the before-reveal separation procedure. A newly extracted dataset cannot be asserted to be the exact historical run merely because it uses the same source collection.

The two-city baseline writes a local experiment log and produces historical full-target cross-city diagnostics. Those scores are excluded from the final canonical tables; the final paper uses the five-city held-out-target-test values. The retained script names and machine output paths are provenance-preserving interfaces, not a recommendation to publish the development history. The public-facing README uses final paper numbering.
