# Selected derived tables

`canonical_tables/` contains aggregate numerical results used by integrity tests. `figure_source_tables/` contains chart-level source data, including seven city-level map points/window descriptors; these are **not** sampled benchmark coordinates. `supplementary_tables/` contains the eleven full-precision companion CSVs for the final supplementary tables. `outputs/` contains compatibility copies where the retained plotting scripts expect them.

These tables are selected derived research outputs, not a release of raw AlphaEarth vectors, Dynamic World labels, ESRI/Impact Observatory rasters, GHSL rasters, or Natural Earth geometries. The status of a code license does not automatically cover table/data reuse; author review and provider attribution remain necessary.
